# Prompt for ChatGPT: the SonRise avatar kit

Give everything inside the block below to ChatGPT (a model with Python / a code tool works best, because the kit should be *generated by a script*, not drawn file by file).
Send the file it produces (`sonrise-avatar-pack.json`, plus the preview sheets) back to the app's developer.

````text
You are an illustrator and a Python programmer. Build a complete, original, layered "paper-doll" avatar kit for a calm, friendly mobile app (SonRise) used by children and adults, including people with ADHD and anxiety. Users build their own avatar from parts (face shape, hair, eyes, mouth, clothes, accessories, a small companion...), pick colours, and the avatar is animated. I (the app) do the animating; you only draw static SVG parts that stack perfectly. The result must be ONE JSON file, generated by a Python script you write and run (do not hand-write hundreds of files; use parametric drawing functions so every variant is consistent).

WORK IN STAGES. Do not try to finish in one reply. Stage 1: write the geometry template (below), draw ONLY the base parts (body, head, eyes, brows, nose, mouth, hair x3, outfit x2, arms) and a preview sheet; wait for me to say "continue". Then add the rest in batches of a few slots, always re-running the validator and re-rendering the preview sheet. At the end give me the final files.

## 1. Style
- Flat vector, soft rounded shapes, friendly "sticker" look, warm and calm. No outlines on big shapes; small dark features (eyes, brows, mouth) use the fixed colour #3B2F3A with round stroke caps. No gradients except very subtle ones (optional). No text, no logos, no real brands, nothing copied from existing characters or from a specific artist. Everything must be 100% original and free for commercial use (CC0).
- Gender-neutral and inclusive: every hair style, outfit and accessory is available to everyone; include diverse hair types (straight, wavy, curly, afro puffs, braids, twists), head coverings (headscarf, kippah, turban) and assistive items (glasses, hearing aid, cochlear implant). Never stereotype.
- Calm for anxious users: no scary, sharp, aggressive or creepy options; "angry" is a mild, cute frown.

## 2. Canvas and geometry template (follow exactly so parts line up)
- Every part is an SVG with `viewBox="0 0 256 256"`, `width="256" height="256"`, same origin for all parts. The avatar is a front-facing bust (head, neck, shoulders and upper torso), centered horizontally on x=128.
- Head (face shape): centre (128,112), about 116 wide and 124 tall; chin at y=172; ears at x≈70 and x≈186, y≈118 (ears belong to the head part). Five face shapes: round, oval, square-soft, heart, long. All share the same chin point (128,172), the same neck and the same eye/mouth anchors.
- Neck: x 112–144, y 168–196. Shoulders/torso: from y 188 down to 256, widest x 52–204, rounded shoulders. The bottom edge is cut at y=256 (the image edge).
- Face anchors (all face parts are centred on these): left eye (102,116), right eye (154,116), brows y=96, nose (128,134), mouth centre (128,152), cheeks (84,138) and (172,138). Eyes are ~26 px wide, mouth up to ~44 px wide.
- Hair and hats sit around the head: `hair back` is drawn behind the body, `hair front` in front of the face (bangs etc.). Arms: raised arms must stay inside the canvas.
- Pivot points the app will use for animation (make parts look right when rotated a few degrees around them): body pivot (128,256) bottom centre; head pivot (128,176) at the neck.

## 3. Recolouring: use these CSS classes (the app defines them) AND a default fill
Every shape that should change with the user's colour choice gets BOTH a `class` and a normal `fill` attribute with the default colour:
- `c-skin` (skin; default fill #E8B48A), `c-hair` (hair, eyebrows, facial hair; default #4A2E1B), `c-cloth` (main clothing colour; default #6C5CE7), `c-cloth2` (second clothing colour; default #FDCB6E), `c-accent` (accessory/hat/frame/companion colour; default #00B894), `c-eye` (iris colour; default #6A4A2F).
- Shading and highlights are NOT separate colours: draw them as black or white shapes with `fill-opacity` between 0.08 and 0.25, so they work on any colour.
- Anything else (white of the eyes, teeth, dark features, jewellery) uses fixed colours.
Example: `<path class="c-skin" fill="#E8B48A" d="..."/>`.

## 4. SVG rules (the app validates strictly; files that break these are rejected)
- Allowed elements only: svg, g, path, circle, ellipse, rect, line, polyline, polygon, defs, clipPath, linearGradient, radialGradient, stop.
- Allowed attributes only: xmlns, viewBox, width, height, id, class, d, cx, cy, r, rx, ry, x, y, x1, y1, x2, y2, points, fill, fill-opacity, stroke, stroke-width, stroke-linecap, stroke-linejoin, opacity, transform, clip-path, offset, stop-color, stop-opacity, gradientUnits, gradientTransform.
- FORBIDDEN: script, style (element and attribute), image/foreignObject/use/a, text/tspan, filter, mask, animate*/set, any href/xlink:href, any url() except `clip-path="url(#id)"` or `fill="url(#id)"` pointing to an id defined inside the same file, event attributes.
- Give ids a unique prefix per part (for example `hairstyle-curly-front-grad1`) so several parts can sit on one page without clashes.
- Keep each part small: 4 KB or less (round numbers to 1 decimal), the whole kit at most 1.5 MB.
- A part that has nothing to draw is an empty `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 256 256" width="256" height="256"/>`.

## 5. The slots and their options (stack order from back to front)
Each option has: `id` (lowercase-with-dashes), `name` {en, he} (short, neutral wording; Hebrew in neutral/plural forms), `unlock` (a level from 1 to 14: about 40% of options at 1, the rest spread up to 14, fancier ones later), and `variants` (below).

1. `backdrop` - 10 round or soft-shape backgrounds behind the character (sunrise, clouds, stars, forest, sea, rainbow, space, flowers, plain-circle, confetti). Use c-accent for the main shape and fixed pale colours otherwise. variants: `default`.
2. `hair` - 18 styles: buzz, short-straight, short-curly, afro, afro-puffs, side-part, spiky, pixie, bob, long-straight, long-wavy, long-curly, braids, pigtails, ponytail, bun, topknot, twists; plus `bald` (empty parts). variants: `back` (drawn BEHIND the body) and `front` (in front of the face). Colour class c-hair.
3. `body` - ONE option `body`: neck + shoulders + torso in skin colour (c-skin). variants: `default`.
4. `outfit` - 14: t-shirt, hoodie, dress, overalls, pyjamas, sports-jersey, school-shirt, superhero (cape goes in the accessory slot), scarf-sweater, raincoat, apron, lab-coat, collar-shirt, cozy-cardigan. Colours c-cloth / c-cloth2. variants: `default` (covers the torso, leaves the neck visible).
5. `arms` - ONE option `arms` with sleeves in c-cloth and hands in c-skin (short sleeves). variants (all full-canvas, same shoulders): `rest` (hanging at the sides), `wave_a` and `wave_b` (one hand raised and waving, two frames), `cheer` (both arms up), `dance_a` and `dance_b` (arms out to the sides, two frames), `alert` (both hands up near the face), `think` (one hand touching the chin).
6. `head` - 5 face shapes (round, oval, square-soft, heart, long) with ears. variants: `default`. c-skin.
7. `cheeks` - blush, freckles, rosy-big, none. variants: `default`.
8. `eyes` - 8 styles (dot, round, big-shiny, almond, cute-sleepy-lashes, wide-set, sparkle, simple-lines). variants = states: `open`, `closed` (used for blinking and sleep), `happy` (smiling arcs), `wide` (surprised), `look_left`, `look_right`, `sad` (slightly down-slanted), `sleepy` (half closed). Iris class c-eye.
9. `brows` - 5 styles. variants: `neutral`, `raised`, `worried`, `sad`, `angry` (a mild cute frown). Colour c-hair.
10. `nose` - 5 styles (dot, button, small-line, round, tiny-triangle). variants: `default`.
11. `mouth` - 3 styles (simple, cat-smile, toothy-smile). variants = expressions: `smile`, `big` (open happy), `neutral`, `sad`, `surprised` (round o), `hmm` (thinking, slightly crooked), `flat` (sleeping), `cheer` (very wide open), `worried` (small wobbly), `proud` (confident smirk).
12. `facial_hair` - none, stubble, mustache, short-beard, full-beard (adult options, unlock later). variants: `default`. c-hair.
13. `glasses` - none, round, square, cat-eye, sunglasses, goggles-cute. Frame colour c-accent. variants: `default`.
14. `headwear` - 12: none, cap, beanie, sun-hat, party-hat, crown, flower-crown, headphones, bow, headband, cat-ears, headscarf, kippah, turban (headscarf/kippah/turban are in c-cloth; others c-accent). variants: `default`.
15. `accessory` - 10: none, scarf, bow-tie, necklace, backpack-straps, cape (back part), medal-ribbon, hearing-aid, cochlear-implant, star-pin. variants: `front` and `back` (back drawn behind the body; use an empty svg if not needed).
16. `companion` - 8 small buddies that sit in the bottom-right corner (inside x 168–248, y 176–256): cat, dog, bunny, bird, turtle, dragon-baby, robot, star-friend. variants: `a` and `b` (two frames of a tiny idle movement, such as blinking or a tail flick). Colour c-accent / c-cloth2.
17. `effects` - small overlays that appear on top for animations (NOT user-selectable, fixed ids): `sparkles`, `hearts`, `notes`, `zzz`, `exclamation`, `thought` (a thought bubble beside the head), `stars`, `sweat`. Each has variants `a` and `b` (two frames that differ a little, for a twinkle). Fixed colours, soft.

## 6. How the app will combine them (draw so these combos look good)
- idle: arms.rest, eyes.open (blinks to eyes.closed for a moment), mouth.smile, brows.neutral.
- wave: arms.wave_a/wave_b alternate, mouth.big, brows.raised.
- cheer: arms.cheer, eyes.happy, mouth.cheer, effects.sparkles.
- dance: arms.dance_a/dance_b alternate, eyes.happy, mouth.big, effects.notes.
- sleep: arms.rest, eyes.closed, mouth.flat, effects.zzz.
- alert: arms.alert, eyes.wide, mouth.surprised, brows.raised, effects.exclamation.
- think: arms.think, eyes.look_left, mouth.hmm, brows.raised, effects.thought.
- Feelings (for a "how do I feel" screen): happy = eyes.happy + mouth.big; calm = eyes.closed + mouth.smile; sad = eyes.sad + brows.sad + mouth.sad; worried = eyes.open + brows.worried + mouth.worried; angry = brows.angry + mouth.neutral; tired = eyes.sleepy + mouth.flat; excited = eyes.wide + mouth.cheer + effects.stars; proud = eyes.happy + mouth.proud + effects.sparkles.
So every eye style must work with every mouth style and every brow style on every face shape without overlapping badly.

## 7. Palettes (put these exactly in the JSON; the app lets the user pick from them)

## 8. The JSON file (exact structure)
Write ONE file `sonrise-avatar-pack.json`, UTF-8:
{
  "format": "sonrise-avatar-pack", "version": 1, "canvas": 256,
  "name": { "en": "...", "he": "..." },
  "palettes": { "skin": [...], "hair": [...], "cloth": [...], "accent": [...], "eye": [...] },
  "slots": {
    "backdrop": { "order": 1, "options": [ { "id": "sunrise", "name": {"en": "Sunrise", "he": "זריחה"}, "unlock": 1, "variants": { "default": "<svg ...>...</svg>" } }, ... ] },
    "hair": { "order": 2, ... }, "body": { "order": 3, ... }, ... (all 17 slots, using these keys: backdrop, hair, body, outfit, arms, head, cheeks, eyes, brows, nose, mouth, facial_hair, glasses, headwear, accessory, companion, effects)
  }
}
- "variants" maps each variant name from section 5 to the SVG as a string (single line, valid JSON escaping).
- Slots where "none" is an option (glasses, headwear, facial_hair, accessory, cheeks, hair "bald", companion "none") use an option whose variants are empty svgs.
- Hebrew names: short, natural, gender-neutral (for example "שיער קצר", "משקפיים עגולים").

## 9. Validate and show me (do all of this yourself, with code)
1. A validator script that checks every SVG: well-formed XML, root attributes, only allowed elements/attributes, no forbidden things, size limits, every referenced id exists, that the variants required in section 5 are all present, that the JSON matches section 8 and each option has en + he names and an unlock level 1-14.
2. Render PREVIEW SHEETS to PNG (for example with cairosvg or inkscape): (a) every option of every slot on a neutral base character, in a labelled grid; (b) 12 random complete avatars with different skin/hair/cloth colours (apply the colours by replacing the fill of the class c-skin, c-hair, etc. in a copy); (c) the 7 animations and the 8 feelings of one avatar, two frames each.
3. Look at the sheets yourself and fix: misaligned parts, hair that hides the eyes, hats that cut the face, parts leaving the canvas, an option that is not visibly different from another.
4. Deliver: `sonrise-avatar-pack.json`, the preview PNG sheets, and the generator script (`build_avatar_pack.py`) so I can regenerate. Tell me the number of options per slot and the total JSON size.

Start with Stage 1 now.
````

## Notes for the developer
- The app will read `sonrise-avatar-pack.json` with a strict allow-list parser (same rules as section 4), recolour through the six `c-*` classes, and animate by swapping `variants` (blink, wave, dance frames) plus CSS transforms around the two pivots.
- Existing animal characters, photo and GIF avatars stay.
