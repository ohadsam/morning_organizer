# Prompt for ChatGPT: the SonRise icons, illustrations, animations, logo and style packs

Give everything inside the block below to ChatGPT (a model with Python and a code tool works best: the kit must be *generated by scripts*, not drawn one file at a time).
Send back the ZIP it produces (`sonrise-visual-kit.zip`) to the app's developer.

````text
You are a senior brand and icon designer and a Python programmer. Build ONE complete, original, consistent visual kit for a calm mobile app called SonRise (a routines and focus app; Hebrew first, right-to-left, and English). It includes: the logo and app icons, a full icon set, colourful task icons, feeling faces, badges and awards, small animated celebrations, illustrations, and EIGHT switchable style packs (each pack re-colours and re-styles the same artwork, so users can change the look of the whole app). Everything is delivered as a ZIP with one big JSON file plus the app-icon image files, all generated by a Python script you write and run.

WORK IN STAGES and wait for me to say "continue" between stages: Stage 1 = style system + the 40 UI icons + the logo/app icon + one animation + preview sheets. Stage 2 = feature icons and task icons. Stage 3 = feelings, badges, awards. Stage 4 = animations and illustrations. Stage 5 = the remaining packs, validation, packaging. After every stage run the validator and show me preview sheets.

## 1. Who it is for, and the design principles
- Users: children and adults, many with ADHD, anxiety or organisation difficulties; also therapists and parents. The app must feel calm, safe, warm and clear, never busy or loud.
- Few shapes, big readable silhouettes, generous spacing, rounded forms, one consistent visual language across EVERY asset (same corner radius logic, same stroke caps, same level of detail, same light direction: soft, from the top).
- Original work only: nothing copied from existing icon sets, characters, logos or a living artist's style; no brands, no text in icons, no real people. Free for commercial use (CC0).
- Inclusive and gender-neutral; no stereotypes. Hebrew and English users are equal: icons must not depend on reading direction, except where a direction is the meaning (back, next, undo): provide those as a pair `*-start` / `*-end` (start = the side where text begins) so the app can mirror them for right-to-left.
- Accessibility: every glyph must stay recognisable at 20 px; colour is never the only signal; contrast of any text-like glyph or thin line against the pack background at least 3:1 (UI icons) and body-colour pairs at least 4.5:1.
- Motion safety: all animations are gentle: no flashing, nothing faster than 3 changes per second, loops at least 800 ms, small amplitudes. The app also has a "calm animations" switch that turns every animation off, so each animated asset must look complete and good as a still image (its first frame).

## 2. The style system (do this first)
Existing brand reference (keep the spirit, improve the execution): the current logo is a round-cornered square with a night-purple sky that warms to orange at the horizon, a golden sun half-risen over a dark horizon line, short golden rays, and the wordmark "SonRise" in cream. Brand colours today: purple #6C5CE7, orange #FF9F6B, sun gold #FFC233, deep ink #1F1B3A, soft background #F6F4FF. The "Rise" in the name means a gentle new start every morning.

Eight style packs. They share the SAME geometry; a pack only changes colours, line weight, corner softness, which icon variant is used, and decoration:
1. `sunrise` (default): warm and friendly. Brand #6C5CE7. Rounded, medium line (2 px on a 24 grid), duotone icons.
2. `ocean`: calm blues. Brand #0B6FC4. Soft, medium line, duotone.
3. `forest`: natural greens. Brand #1F7A4D. Soft organic feel, duotone.
4. `sunset`: warm coral and amber. Brand #C2410C. Cosy, filled icons.
5. `candy`: playful for young children. Brand #BE185D. Chunky 2.6 px line, bubbly, filled icons with a light inner highlight.
6. `slate`: neutral and professional for adults. Brand #475569. Fine 1.75 px line, line icons.
7. `calm-mono` (low-stimulation, sensory-friendly): ONE muted hue family only, very soft contrast between shapes, thin line, no bright accents, no gradients. For people overwhelmed by colour.
8. `bold-focus` (high clarity, for attention difficulties and low vision): high contrast, thick 3 px line, simple solid shapes, strong colour separation, minimal detail.
Each pack defines TOKENS for light and for dark mode: `bg`, `surface`, `ink` (main text/icon colour), `muted`, `line`, `brand`, `brand2`, `accent`, `good`, `warn`, `bad`, and the eight artwork colours `k1..k8` (see section 3). Compute and print the contrast ratios of ink/bg, ink/surface, muted/bg, brand/bg (for large text), and fix any that fail (ink pairs 4.5:1; brand vs surface 3:1). Also give each pack six "method accent" colours so the app can tint things by treatment method and difficulty: `cbt`, `cogfun`, `nlp`, `adhd`, `anxiety`, `organize` (plus `motivation`) - a calm, distinct hue for each that works on the pack's background.
Pack JSON also states: `strokeWidth` (the 24-grid line width), `iconVariant` (`line`, `duotone` or `filled`), `corner` (`soft`, `round`, `chunky`), `mood` (a one-sentence description in en and he), and which methods/difficulties it suits best (for example calm-mono suits anxiety and sensory sensitivity; bold-focus suits ADHD; candy suits young children; slate suits adults).

## 3. How artwork is coloured (so one drawing serves all packs)
- UI and feature icons are drawn on a 24x24 grid (`viewBox="0 0 24 24"`) with stroke/fill using `currentColor` through the class `i-ink`; secondary tint areas use `i-tint` (the app sets it to the ink colour at a low opacity). Strokes use class `i-sw` (the app sets stroke-width from the pack).
- Colourful artwork (task icons, feelings, badges, awards, illustrations, logo) is drawn on a 64x64 grid (illustrations 256x256, logo 512x512) and uses ONLY these classes for colour, each with a normal default `fill` too: `k1` primary brand colour (default #6C5CE7), `k2` secondary (#FF9F6B), `k3` third (#FFC233), `k4` light tint (#EDE9FF), `k5` dark shade (#2B2487), `k6` warm accent (#FF7675), `k7` cool accent (#55EFC4), `k8` skin-neutral (#F6CFAB). Plus fixed colours (not classes) only for white (#FFFFFF), eye/ink dark (#3B2F3A) and for objects that must look natural. Shading and highlights = black or white shapes with `fill-opacity` 0.08-0.25.
- Because every pack sets k1..k8, the SAME drawings change character between packs. Design them so they look good with any sensible set of eight colours, and also good in the dark-mode token sets.

## 4. SVG rules (the app validates strictly; files that break these are rejected)
- Allowed elements only: svg, g, path, circle, ellipse, rect, line, polyline, polygon, defs, clipPath, linearGradient, radialGradient, stop.
- Allowed attributes only: xmlns, viewBox, width, height, id, class, d, cx, cy, r, rx, ry, x, y, x1, y1, x2, y2, points, fill, fill-opacity, stroke, stroke-width, stroke-linecap, stroke-linejoin, opacity, transform, clip-path, offset, stop-color, stop-opacity, gradientUnits, gradientTransform, pathLength.
- FORBIDDEN: script, style (element and attribute), image, foreignObject, use, a, text, tspan, filter, mask, animate, animateTransform, set, any href or xlink:href, event attributes, any `url()` except `fill="url(#id)"`, `stroke="url(#id)"` or `clip-path="url(#id)"` with an id defined in the same file. Text such as the wordmark must be converted to outlined paths.
- Unique ids: prefix every id with the asset id.
- Size limits: UI icons <= 1.2 KB each, task icons and feelings <= 3 KB, badges/awards <= 4 KB, animated assets <= 8 KB, illustrations <= 16 KB, logo parts <= 12 KB. Round coordinates to 1 decimal (2 for the logo). Whole JSON <= 4 MB.
- Every icon must have a unique, meaningful silhouette; no two icons may be near-duplicates.

## 5. Animation hooks (you draw still layers; the app animates them with CSS)
SMIL and CSS inside the SVG are not allowed. Instead, put the parts that should move in their own `<g>` with one of these classes (the app defines the motion; the geometry should be centred around the natural pivot of that group):
`a-spin` (slow rotation), `a-pulse` (gentle grow and shrink), `a-bounce` (small hop), `a-float` (slow up and down), `a-wiggle` (tiny tilt left and right), `a-twinkle` (opacity breathing), `a-draw` (the stroke draws itself: give the path `pathLength="1"`), `a-rise` (moves up into place once), `a-pop` (scales in once), `a-fade` (fades in once), `a-orbit` (travels slowly around a circle), `a-sway` (like a plant in a breeze), `a-shine` (a highlight sweeps across). Add a delay class to stagger: `d1` ... `d6`.
For two-frame animation (a blink, a flap), draw two groups `f1` and `f2`; the app alternates them. Each animated asset also states in its JSON `loop` (true or false) and `ms` (one cycle in milliseconds, 800-6000).
````
